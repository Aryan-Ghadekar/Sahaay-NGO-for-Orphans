# Sahaay-NGO-for-Orphans

Sahaay is a full-stack NGO management platform designed to enable the coordination between donors, volunteers, NGO staff, and administrators. Built using React, Node.js, Express, and Supabase, the platform provides role based access to manage volunteers, beneficiaries, programs, events, applications, donations, attendance, and organizational impact. It centralizes NGO operations while providing a transparent public facing interface for donors and supporters to explore ongoing initiatives, upcoming events, and the impact created by the organization.
